Same complaint, different agency

South Korea's nationwide civic reporting platform receives more than ten million citizen safety reports a year, routed to 12 agencies whose sizes differ by 1,292:1. The correct agency is not a function of the report text alone — identical complaints are legitimately routed to different agencies depending on where they were filed. This demo shows the deployed remedy: geocode each report to 1 of 229 coarse districts and prepend the district to the text as two plain tokens.

How a coordinate becomes two tokens

The entire intervention is a dataset-build step plus one string operation. No new vocabulary, no architecture change, no extra serving path. The released code is the exact logic used to build the paper's datasets.

1

GPS point

(37.2636, 127.0286)

Every report carries the filing coordinates.

2

Point-in-polygon

경기도 수원시

STRtree lookup over 3,558 boundary polygons, coarsened to 229 districts. Offshore points snap to the nearest polygon. The coordinates are then discarded.

3

Prepend as plain tokens

[경기도 수원시] 도로에 포트홀이…

The district pair is prepended to the text and segmented by the ordinary subword tokenizer.

4

Encoder + class-balanced loss

p(agency | text, district)

A 110M-parameter Korean encoder scores 12 agencies. High confidence auto-routes; low confidence defers to a human.

# src/geocode.py — coordinates → district (the exact production logic)
geocoder = DistrictGeocoder("HangJeongDong_ver20260401.geojson")
sido, sigungu = geocoder.lookup(37.2636, 127.0286)   # ('경기도', '수원시')

# src/region_tokens.py — district → model input
def build_model_input(text, sido, sigungu):
    return f"[{sido} {sigungu}] {text}"
